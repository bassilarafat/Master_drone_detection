## Official comparison · fixed epoch 100

All six completed runs use Clean_v2 Validation, 1,827 images and 1,867 GT objects. The named sealed research exporter computes 101-point interpolated AP over IoU .50:.05:.95. P/R/F1 and counts use confidence .25 and one-to-one IoU .50. All AP predictions use floor .001. The evaluator uses standard NMS .70, maxDet 300 and batch 1 at 960 px. Size bins use original-image box area. The official latency field is unavailable.
